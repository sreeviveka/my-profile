# Sreeviveka Senthil — Personal Portfolio

A responsive personal profile website built with plain HTML and CSS.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — colours, layout, responsive styling

## Run locally
1. Extract the ZIP file.
2. Open the `profile_website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Personalise before publishing
Open `index.html` and replace:
- `your.email@example.com` with your email address
- `your-github-username` with your GitHub username
- `your-linkedin-username` with your LinkedIn profile username

Review the education, skills, and project summaries and update them to reflect your exact experience.

## Publish using GitHub Pages
1. Sign in at https://github.com.
2. Create a **public** repository named `profile-website`.
3. Upload `index.html`, `style.css`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. After deployment, your site should be available at:

   `https://YOUR-GITHUB-USERNAME.github.io/profile-website/`

Your repository URL will be:

`https://github.com/YOUR-GITHUB-USERNAME/profile-website`

The URLs above are templates. A real GitHub URL is available only after you create and publish the repository from your GitHub account.
